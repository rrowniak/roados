## Goal

Close clauses **(b)** and **(c)** of row **`L6b`** in `doc/ui/DEMO_APPLICATION.md`

the one it was set on, and a stored value that survives an enumeration change and

## Context

**Decision: (B), narrowed — `ModeScope<K>`, a map from node handle to mode whose lookup walks the parent chain to the nearest entry, resolved by the owner before layout and written into each widget through a setter.** The walk is `node.rs`'s private `descends_from`; the mode is written into the widget because `WidgetNode` has no arena and `Property::bind` gets no handle, so it is **not a `Property`**.

### The theme gains no token, and row `L9` is why

Clause **(a)** of `L6b` is row `L9`'s and is not built: `theme.rs` is untouched, `const TOKEN_COUNT: usize = 33;` stays `const` and private, and `dark_and_light_define_every_token` keeps `assert_eq!(ThemeToken::all().len(), 33)`.

**`Snapshot` is a set of deferred writes restored in reverse**, the defroster's three heterogeneous values type-erased by `widgets::Callback<()>`; each `save` captures the value, not the property. **`Segmented`'s `f32` value is a point on a scale, not an index** (`Slider::set_step`'s *"cannot reach 1"*). `sync_climate_mode` sits beside `sync_toggle_state` guarded by `if wanted != applied`; **no `mark_dirty` is needed because no placed rect depends on the mode.**
